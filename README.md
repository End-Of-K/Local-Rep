# 🚀 JS Daily Practice Starter Kit

このリポジトリは、HTML/CSS/JavaScriptによるWebフロントエンドの継続的なコーディング練習のために作成された、最小限のスターターキットです。

**VS Codeの拡張機能「Live Server」**を使用することで、すぐにブラウザ上で動作を確認できます。

## ⚙️ 動作環境

* **ブラウザ:** Google Chrome, Mozilla Firefox など
* **エディタ:** Visual Studio Code (VS Code)
* **必須拡張機能:** Live Server

## 📂 プロジェクト構成

このテンプレートは、以下の3つのファイルから構成されており、相互にリンクされています。   
├── index.html # Webページの構造（エントリポイント）   
├── style.css # Webページのデザインとスタイル   
└── script.js # JavaScriptによる動作ロジック

## 🛠️ 起動手順

プロジェクトをローカル環境で起動し、開発を行うための手順です。

### 1. 必須拡張機能のインストール

VS Codeを開き、以下の拡張機能をインストールしてください。

* **Live Server:** (Ritwick Dey 氏提供) - ファイルを保存するたびに自動でブラウザをリロードし、開発効率を大幅に向上させます。

### 2. プロジェクトの起動

1.  VS Codeでこのリポジトリのフォルダを開きます。
2.  `index.html` ファイルをエディタで開きます。
3.  `index.html` のエディタ画面内でマウスを右クリックし、「**Open with Live Server**」を選択するか、画面右下にある **Go Live** ボタンをクリックします。

これにより、自動的にWebブラウザが起動し、開発中のWebページが `http://127.0.0.1:5500/index.html` のようなURLで表示されます。

### 3. 開発とデバッグ

* `index.html`、`style.css`、または `script.js` に変更を加えてファイルを**保存**すると、ブラウザが自動的にリロードされ、即座に結果を確認できます。
* JavaScriptの動作確認やデバッグを行う際は、ブラウザで右クリックし、「**検証**」または「**要素を調査**」から**コンソール**タブを開いてください。

## 🔁 新しい課題に取り組む際の運用方法

このテンプレートは、日々の練習で使い回すことを前提としています。

### 1. フォルダを複製して使用する（推奨）

新しい課題に取り掛かる際は、このテンプレートフォルダ（`index.html`、`style.css`、`script.js`が入ったフォルダ）を丸ごとコピーし、新しいフォルダ名（例: `02_Simple_Timer`）に変更して作業を開始してください。これにより、クリーンな状態から新しい課題に集中できます。

### 2. Gitでバージョン管理を行う

日々の成果を記録し、Gitのスキルも磨くために、以下の基本操作を習慣化してください。

1.  **ステージング:** 変更したファイルを準備
    ```bash
    git add .
    ```
2.  **コミット:** 変更履歴を保存
    ```bash
    git commit -m "feat: Simple Timer機能を追加"
    ```
3.  **プッシュ:** 履歴をGitHubに公開
    ```bash
    git push origin main
    ```

**特に、新しい課題ごとにGitのブランチを作成し、メイン（`main`）ブランチを保護することも推奨します。**

```bash
# 新しい課題用のブランチを作成・切り替え
git checkout -b feature/new-task-name
